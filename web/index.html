Piano : de la partition au son

Un programme C++ qui lit une partition texte, calcule la fréquence de chaque note et génère un fichier WAV échantillon par échantillon. Il tourne ici directement dans ton navigateur.

Format de la partition

    
    
      
  • Première ligne : le tempo, 60 ou 120 battements par minute.
    • 
      
  • Puis une note par ligne : octave NOTE altération durée, par exemple 3 DO # 1.
    • 
      
  • Notes : DO RE MI FA SO LA SI. Altération : # (dièse), b (bémol) ou - (aucune).
    • 
      
  • Durée en temps : 1 = noire, 2 = blanche, 0.5 = croche. 3 LA - 1 = 440 Hz.
    • 
    

    
Comment ça marche

    
Le même code C++ que la version console (main.cpp, biblioWAV.cpp) est compilé avec
      Emscripten en WebAssembly. Au clic, la page lui passe le texte ; il calcule les fréquences
      (440 × 2n/12), écrit l’en-tête RIFF/WAVE et les échantillons 16 bits stéréo à 44,1 kHz,
      puis la page joue le fichier obtenu. Les messages affichés ci-dessus sont les cout du programme.
